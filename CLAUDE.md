## Architecture

**Stack**: Next.js 16 App Router · TypeScript · Tailwind CSS v4 · Zustand · Supabase · PWA

### Data Flow

Each feature domain has a dedicated Zustand store in `store/` using `persist` middleware (localStorage). Supabase sync is **non-blocking**: mutations write to local state first, then fire-and-forget upserts to Supabase. On login, `components/SyncBoot.tsx` (mounted in the root layout) calls every store's `fetch*`, which merges Supabase rows with local state (Supabase wins on core fields; local fills fields the server lacks).

`lib/sync-pending.ts` records rows whose upsert hasn't been confirmed. On fetch, a local row missing remotely is kept and re-uploaded only if it is pending; otherwise it's treated as deleted on another device and dropped. Every store sync function must `markPending` before and `clearPending` after a successful upsert.

### Auth

Supabase Auth (email/password with email confirmation, Google OAuth). `lib/auth-context.tsx` provides `AuthProvider` and `useAuth()`; auth state lives in React context, not Zustand. `components/auth/AuthGate.tsx` wraps the whole shell in `app/layout.tsx`, so every route requires login. OAuth/email callback: `app/api/auth/callback/route.ts` (only same-origin `next`; errors forwarded as `?auth_error=`).

localStorage is per browser, not per account: `lib/local-data-owner.ts` records the owning user id and wipes another account's local data on login; `signOut` wipes it too. Add any new persisted store key to `USER_DATA_KEYS` there.

### Pages

All pages are under `app/` using the App Router. The shell layout (`app/layout.tsx`) wraps everything in `AuthProvider` and renders `<Sidebar>` + `<MobileHeader>`. Core feature pages: `/todo/daily`, `/todo/all`, `/board` (kanban), `/calendar`, `/routine`, `/tracker`, `/projects`, `/projects/[id]`, `/ideas`, `/links`, `/brainstorm`, `/mindmap`, `/news`, `/archive`, `/settings`.

### Database Schema

Defined in `lib/database.types.ts`. Synced tables: `todos`, `projects`, `ideas`, `notes`, `habits`/`habit_logs`, `links`, `tracker_sessions`, `routines` — all with RLS `auth.uid() = user_id`. Mindmaps, news, agent and UI state are localStorage only. SQL migrations live in `scripts/*.sql` and are applied manually in the Supabase SQL editor.

### API Routes

- `app/api/auth/callback/route.ts` — Supabase OAuth callback
- `app/api/openai/generate-prd/route.ts` — GPT-powered PRD generation for projects

### PWA

Service worker at `public/sw.js` (no caching on purpose), registered via `components/ServiceWorkerRegistrar.tsx`. Icons in `public/icons/`, generated by `scripts/generate-icons.mjs`.
