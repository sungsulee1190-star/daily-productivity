# Daily Productivity — 할일 / 루틴 / 링크 / 트래커

The user's own productivity web app. Data lives in Supabase; this skill logs in **as the user**, so row-level security restricts every call to their rows only.

## Setup (once per computer)

Add to `${HERMES_HOME:-~/.hermes}/.env` (the user does this — never ask them to paste the password into chat):
```
DP_EMAIL=<app login email>
DP_PASSWORD=<app login password>
```
If `whoami` fails with `DP_EMAIL / DP_PASSWORD not set`, tell the user to add these lines.

Run everything through the `terminal` tool:

```bash
DP="${HERMES_HOME:-$HOME/.hermes}/skills/productivity/daily-productivity/scripts/dp.py"
python3 $DP whoami
```

## Commands

| Command | What it does |
|---|---|
| `list <table> [--q "<postgrest>"] [--limit N]` | Read rows (default newest first, limit 200) |
| `get <table> <id>` | One row |
| `add <table> '<json>'` | Insert (object or array). `user_id` / `updated_at` are filled in automatically |
| `update <table> <id> '<json patch>'` | Partial update; `updated_at` is set automatically |
| `delete <table> <id>` | Delete one row |

`--q` uses PostgREST filter syntax, joined with `&`:
`completed=eq.false`, `due_date=lte.2026-11-03`, `title=ilike.*보고서*`, `tags=cs.{회의}`, `order=due_date.asc`, `select=id,title,due_date`.

## Tables the web app shows

**todos** — 할일 (daily / all / board / calendar pages)
- `title` text (required) · `memo` text · `priority` `low|medium|high`
- `due_date` date `YYYY-MM-DD` (the app's "deadline")
- `clip` `work|personal` (default `work`) · `tags` text[]
- `completed` bool · `completed_at` timestamptz
- `kanban_status` `backlog|inprogress|done|hold`
- `subtasks` jsonb: `[{"id":"<uuid>","title":"...","completed":false,"startDate":"YYYY-MM-DD","dueDate":"YYYY-MM-DD"}]`

**routines** — 루틴: `title`, `type` `daily|weekly|monthly`, `checked_days` / `checked_weeks` / `checked_months` text[], `hidden` bool

**links** — 링크: `title`, `url`, `emoji` (default 🔗)

**tracker_sessions** — 트래커: `name`, `month` (`YYYY-MM`), `items` jsonb, `start_date`, `end_date`. `id` is auto-generated by the script.

**projects** — `name`, `status` `active|paused|done`, `repo_url`, `notes`, `tech_stack` text[]

**ideas** — `title`, `description`, `status` `inbox|ready|in_progress|done`, `priority`, `cli_tool` `claude|codex|gemini|auto`

**notes** — `title`, `content`

## Recipes

```bash
# Today's open todos
python3 $DP list todos --q "completed=eq.false&due_date=lte.$(date +%F)&order=due_date.asc&select=id,title,due_date,priority,clip"

# Add a todo
python3 $DP add todos '{"title":"주간보고 작성","due_date":"2026-11-05","priority":"high","clip":"work","kanban_status":"inprogress"}'

# Complete it
python3 $DP update todos <id> '{"completed":true,"completed_at":"'"$(date -u +%FT%TZ)"'","kanban_status":"done"}'

# Save a link
python3 $DP add links '{"title":"Supabase docs","url":"https://supabase.com/docs","emoji":"📚"}'
```

## Rules

- **Confirm with the user before `delete`** or before updating more than 5 rows at once.
- When editing `subtasks` or `tags`, `get` the row first and send the full new array — the patch replaces the whole value.
- The web app loads data when it opens, so changes appear after the user refreshes the page.
- Never print `DP_PASSWORD`.
- On `HTTP 400 invalid_credentials`, the email/password in `~/.hermes/.env` is wrong — tell the user.
